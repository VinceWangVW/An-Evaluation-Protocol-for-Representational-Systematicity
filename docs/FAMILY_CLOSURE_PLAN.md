# Phase 18: G2 Family-Level Closure

`Phase 18` is the final closure test for the bounded `{G1_binding, G2_distributed_geometry}` paper claim. It does not search for more `H1-like` points. It asks whether `G2` still has any plausible endogenous causal-object path left at the family level.

## Frozen Framing

- `G1_binding`: bounded hypothesis-final success
- `G2_distributed_geometry`: partial adjudication unless `Phase 18` reaches family-level closure
- repository strongest framing stays `bounded protocol + partial adjudication` until `Phase 18` reaches a final branch

## Closure Threshold

`Phase 18` uses exactly `3` orthogonal object classes:

- `C1`: decoder-step interaction-event class from `Phase 17`
- `C2`: cross-step bridge class
- `C3`: query-source relation class

The branch may end only in:

- `U-supported`
- `L-supported`
- `T-supported / family-final`

## Step A: Observability Audit

Run the audit first on the frozen stable `H2/H0` controls using exactly three aligners:

- `A1`: current leftmost exact subsequence aligner
- `A2`: slot-aware literal field aligner
- `A3`: teacher-forced bridge aligner

Audit decision rule:

- If `agent` or `theme` reaches aligned-step rate `>= 0.8` under `A2` or `A3` while `A1 < 0.2`, rerun `C1` under the best aligner.
- If all aligners keep `agent/theme < 0.2` while `predicate >= 0.8`, observability is sealed as `predicate-dominant`.
- Otherwise observability is ambiguous and `Phase 18` halts.

## Step B: Family-Level H2 Closure

For all three classes:

- finish discovery
- run the same `H2 necessity` gate
- keep `generic_decoder_gain` mandatory as a matched control

`T-supported / family-final` is impossible unless:

- observability is sealed
- `C1`, `C2`, and `C3` all finish discovery
- all three classes fail to produce any `H2`-passed object

## Step D: Family-Level Stop Rule

`U-supported`

- at least one class yields an `H2`-passed object
- and at least one direct `H1` object passes the global rescue gate

`L-supported`

- no global direct `H1`
- but slice-local `H1` passes in at least two accepted slices

`T-supported / family-final`

- observability is sealed
- all three classes fail the `H2` necessity gate
- direct `H1` fails globally and slice-locally
- existing `H0/H2` stability remains intact
